# RecoverAI Backend

Autonomous Revenue Recovery Agent FastAPI Backend.

## Overview
- **FastAPI** async RESTful API
- **SQLAlchemy 2.0** + **asyncpg** for async PostgreSQL operations
- **Alembic** schema migrations
- **LangGraph** multi-agent pipeline
- **XGBoost** calibrated tabular classifier
- **Razorpay** test mode integration
